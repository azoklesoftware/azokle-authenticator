# Release Changelog - Version 3.2.0

**Date:** October 12, 2026  
**Platform:** Android (`azokle-authenticator`)

## 🚀 Summary of Changes

Version 3.2.0 introduces complete multi-language localization with instant in-app switching across 34 languages, a hardened production release pipeline featuring memory-backed keystore decoding and strict signature verification, official F-Droid inclusion recipes with Fastlane store metadata, and comprehensive security vulnerability scanning workflows.

---

## 🎨 Feature & Component Breakdown

### 1. 🌐 Complete Multi-Language Localization Engine
- **In-App Language Switching**: Resolved an issue where changing the interface language left the UI in English. The app now immediately refreshes and displays the selected language.
- **34 Language Support**: Added localized string resources for German (`de`), French (`fr`), Spanish (`es`), Italian (`it`), Russian (`ru`), Japanese (`ja`), Hindi (`hi`), Arabic (`ar`), Dutch (`nl`), Portuguese (`pt`), Polish (`pl`), Turkish (`tr`), and 22 additional regional languages.
- **Android 13+ Per-App Locales**: Configured `android:localeConfig="@xml/locales_config"` and integrated modern `AppCompatDelegate.setApplicationLocales()` across application cold-start and runtime preferences.
- **Context & Configuration Wrapper**: Updated `AzokleAuthActivity` with `attachBaseContext()` wrapping `createConfigurationContext()` with `LocaleList` for seamless backward compatibility.

### 2. 🔐 Hardened Release Signing Pipeline
- **GitHub Actions Secrets Integration**: Automated release builds using repository secrets:
  - `ANDROID_KEYSTORE_BASE64`
  - `ANDROID_KEYSTORE_PASSWORD`
  - `ANDROID_KEY_ALIAS`
  - `ANDROID_KEY_PASSWORD`
- **Volatile Memory Keystore Storage (tmpfs)**: Decodes the base64 keystore into `/dev/shm` (RAM-backed shared memory) with strict permissions (`umask 077` and `chmod 400`), ensuring private keys never touch persistent disk blocks.
- **Mandatory Signing & Zero Silent Fallbacks**: Disallowed unsigned releases in the release pipeline; missing credentials immediately fail the build.
- **Strict Signature Verification**: Enforced non-zero verification checks:
  - APK: `apksigner verify --verbose` (APK Signature Scheme v2/v3).
  - AAB: `jarsigner -verify -strict` (full Android App Bundle cryptographic verification).
- **Secure Keystore Erasure**: Post-build random byte overwriting (`dd if=/dev/urandom`) followed by multi-pass shredding and unlinking.
- **Least-Privilege Security**: Set top-level workflow permissions to `contents: read`, separated release creation into a dedicated `contents: write` job, and restricted secret access using GitHub Environment rules (`environment: release`).

### 3. 📦 F-Droid & Fastlane Distribution Compliance
- **F-Droid Metadata Recipe**: Created official build recipe `fdroid/com.azokle.authenticator.yml` and root `.fdroid.yml` targeting `GPL-3.0-or-later` and reproducible builds.
- **Fastlane Store Metadata**: Established `fastlane/metadata/android/en-US/` containing 512x512 app icon, 5 high-resolution phone screenshots, app descriptions, and version changelog (`changelogs/5.txt`).
- **Resilient Build Scripting**: Added graceful fallbacks in `android/app/build.gradle` for Git hash and branch discovery in detached or offline build server environments.

### 4. 🛡️ Security & Dependency Auditing
- Added Dependabot automated dependency alerts and updates (`.github/dependabot.yml`).
- Configured automated security vulnerability scanning and CodeQL static analysis workflows.
