# Release Changelog - Version 3.1.0

**Date:** August 11, 2026  
**Platform:** Android (`azokle-authenticator`)  
**Scope:** Complete UI/UX Overhaul, X (Twitter) Design System Integration & Latency Optimization  

---

## 🚀 Summary of Changes

Version 3.1.0 introduces a ground-up UI/UX modernization of Azokle Authenticator inspired by contemporary, high-performance design languages like X (Twitter) and Material 3. This release focuses on immediate scannability, fluid micro-interactions, clean full-width input form alignment, and a distraction-free aesthetic.

---

## 🎨 Feature & Component Breakdown

### 1. 💳 Outlined Card Design System
- **Theme Transition**: Switched `Widget.AzokleAuth.EntryCardView` and `CompactEntryCardView` from `Widget.Material3.CardView.Elevated` to `Widget.Material3.CardView.Outlined`.
- **Stroke Accents**: Applied subtle `colorOutlineVariant` 1dp strokes across all entry cards and preference modals.
- **Tactile Feedback**: Integrated fluid `@animator/button_press_scale` touch animations on cards, buttons, filter tabs, and interactive headers.

### 2. 🔤 Ultra-Scannable TOTP List
- **Bold Digits**: Upgraded 6-digit TOTP codes (`profile_code`) from thin `sans-serif-light` to heavy `sans-serif-black` across Standard, Compact, Small, and Tile view modes.
- **Pill Filter Tabs**: Transformed group filter chips into sleek 20dp rounded pill tabs (`chip_group_filter.xml`) with horizontal press animations.
- **Header Branding**: Integrated the `32dp x 32dp` Azokle Auth logo (`ic_azokle_auth_iconx`) alongside bold `20sp` title text.

### 3. 📷 QR Code Camera Scanner
- **Dark Mask Overlay**: Added a 60% semi-transparent dark viewfinder overlay mask (`#99000000`) around the scan target area.
- **Target Reticle**: Designed a `270dp x 270dp` Material 3 Outlined box with `24dp` rounded corners, `2.5dp` white border stroke, and a center crosshair guide.
- **Floating Instruction Pill**: Positioned a semi-transparent rounded prompt pill under the reticle instructing users to align QR codes.

### 4. 📝 Add & Edit Entry Form Overhaul
- **Fixed Overhead Gap**: Reduced the hero avatar container height from `250dp` to `140dp`, eliminating vertical dead space above input fields.
- **In-Field Start Icons**: Embedded `app:startIconDrawable` directly inside `TextInputLayout` elements (Name, Issuer, Group, Note, Secret, PIN, Type, Period, Digits, Usage Count) for unified full-width field alignment.
- **Card-Enclosed Modal**: Upgraded the "Add New Entry" bottom sheet dialog into a `16dp` corner-radius outlined Material Card modal.

### 5. ⚙️ Settings & Preference Navigation
- **Direct 1-Tap Settings Access**: Replaced the 3-dots overflow menu on the header toolbar with a direct Settings gear icon (`ic_outline_settings_24`).
- **About Page Integration**: Added the "About" option directly into the main Settings page (`preferences.xml`) with an outline info icon and right chevron.
- **Navigation Chevrons**: Attached right-aligned chevrons (`widget_preference_chevron.xml`) to all dialog and sub-activity preference rows across Appearance, Behavior, Security, Backups, and Import/Export screens.
